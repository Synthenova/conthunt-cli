# ContHunt agent skill

Teaches coding agents to research viral TikTok, Instagram Reels, and YouTube Shorts through ContHunt MCP.

## Install

```sh
npx skills add https://conthunt.app
```

Or from this repository:

```sh
npx skills add Synthenova/conthunt-cli --skill conthunt -g
```

If MCP is not connected, add a server named ContHunt at `https://mcp.conthunt.app/` and sign in when asked.
